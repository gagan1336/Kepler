## 📝 How to Use

1. Create a new note each trading day
2. Name it `YYYY-MM-DD` (e.g. `2026-08-26`)
3. Use the **Daily Market Journal Template** from the Templates folder
4. Fill in pre-market section **before market opens**
5. Update trades and observations **throughout the day**
6. Complete end-of-day checklist **after market closes**
