## 🚀 How to Run Hermes

Open a terminal in `F:\Stock market analysis\hermes_agent\` and run:

```powershell
# One-off: analyse all trades
python main.py analyze

# Today's debrief
python main.py debrief

# Last week's review
python main.py weekly

# Auto-schedule (runs daily + weekly forever)
python main.py watch
```
