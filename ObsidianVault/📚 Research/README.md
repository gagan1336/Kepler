## 📁 How to Add a New Research Note

1. Create a new note in this folder
2. Name it by the **ticker symbol** (e.g. `RELIANCE`, `INFY`, `HDFCBANK`)
3. Use the **Stock Research Template** from the Templates folder
4. Link it from the [[👁️ Watchlist/Watchlist|Watchlist]] if relevant
